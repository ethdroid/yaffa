YAFFA TANZER — RESUME WEBSITE
=============================

Contents
--------
index.html                 The complete resume website. The photos are
                           built into this single file, so it works on
                           its own with nothing else needed.
Yaffa-Tanzer-Resume.pdf    The original PDF resume.

How to view
-----------
Double-click index.html to open it in any web browser (Chrome, Safari,
Edge, or Firefox). Everything runs locally, no internet connection and
no other files are required.

How to publish it online (optional)
-----------------------------------
Because everything is in one file, you can host index.html for free on:
  - Netlify (drag index.html onto app.netlify.com/drop)
  - GitHub Pages
  - Cloudflare Pages

Editing
-------
All text, colors, and layout live inside index.html. Open it in any
text editor to update wording or contact details.
